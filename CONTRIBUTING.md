# Contributing

Open an issue describing a reproducible trigger, expected behavior and actual behavior. Never include API keys or classroom recordings.

Run Node tests and the project validator before proposing changes. IPA-builder tests simulate macOS tools and do not prove a native build. Changes affecting Speech, background audio, SwiftUI gestures or streaming races also need a compatible Mac build and iPad evidence.

Preserve the upstream MIT notices, optional Codable fields for archive compatibility, original speech text and actual audio ranges. Do not add an API key or signing profile to the repository.

## 贡献说明

请在Issue中给出触发步骤、预期和实际行为，不要提供密钥或课堂录音。修改前运行Node检查和工程校验；涉及语音、后台、手势或流式时序的改动，需要Mac编译与iPad证据。保留MIT署名、旧档可选字段兼容、原始识别文字和真实时间范围。
