# Branding assets

The cream/forest-green quill and connected waveform artwork is adapted from a maintainer-supplied reference. An image-editing tool prepared a full-bleed square asset, corrected the continuous waveform and thickened it at the maintainer's request. The selected asset is included in AppIcon and LechoFeather image sets. It is an edited adaptation, not a lossless crop of the small reference.

The native wordmark uses SnellRoundhand-Bold where available and falls back to an italic serif. The app retains Clair's upstream source attribution; its quill artwork is separate from the upstream project's branding.

## 图案说明

米黄底、墨绿羽毛与连续波形基于维护者提供的图案，经过图像编辑适配、波形校正与加粗后选定。AppIcon与首页LechoFeather均使用该版；它不是小尺寸原图的逐像素无损裁切。标题优先使用SnellRoundhand-Bold，不可用时回退斜体衬线。保留Clair上游源代码署名。
